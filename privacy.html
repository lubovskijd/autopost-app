Privacy Policy

Effective date: October 23, 2026

Autopost is a personal publishing tool operated by Daniil Lubovskij for his own accounts only.

What data the app accesses

  • YouTube: with the owner's consent the app uses the scopes youtube.upload and youtube.readonly to upload videos to the owner's channel and to read the channel name for a health check, and youtube.force-ssl to read comments on the owner's videos and reply to comments that contain a keyword.
  • Instagram, Facebook Page and Threads: with the owner's consent the app publishes the owner's posts, reads comments on the owner's own posts and, when a comment contains a keyword, replies to it and sends one private reply to the commenter (Instagram and Facebook) with a link to the owner's Telegram bot.
  • TikTok: with the owner's consent the app uses the Content Posting API to upload videos to the owner's TikTok account and reads basic profile info to confirm which account is connected.

YouTube API Services

Autopost uses YouTube API Services. By using Autopost you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also covered by the Google Privacy Policy.

Data accessed from YouTube: the name and ID of the owner's channel (to confirm the connected account) and the ID of each video Autopost uploads (to show the link). No other YouTube data is read, stored or shared. Autopost does not use cookies and does not place any tracking on devices.

Stored YouTube data (the channel name and the IDs of uploaded videos) is kept only in the local queue file and is deleted on request or when the owner deletes that file. Data that is no longer needed is deleted within 30 days.

How data is used and stored

Access tokens are stored in a local configuration file on the owner's computer and in the owner's private Supabase project (EU, Frankfurt), which runs the scheduled publishing and comment replies. They are used solely for the owner's own accounts and are never sold, shared with or transferred to third parties. No analytics, advertising or tracking are used.

Comment data: for comments that contain the keyword the app stores the comment ID, the commenter's public username, the comment text and the reply sent, so that each person receives only one reply. Comments without the keyword are stored only as an ID and text to avoid processing them twice. This data is kept for up to 12 months and deleted on request, see Data Deletion Instructions.

Autopost's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google Account permissions or in the TikTok app settings under "Security and permissions". Deleting the local configuration file removes all stored tokens. Instructions for deleting comment and questionnaire data: Data Deletion Instructions.

Contact

Questions about this policy can be sent to the support email shown on the app's consent screen.
